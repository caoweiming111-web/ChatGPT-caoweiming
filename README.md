# MakeX Curriculum — Inspire · Explorer · Challenge

MakeX 机器人课程管理系统，支持课程创建、编辑、文档导出和多人协作。

## 直接使用

直接打开 index.html 即可使用（数据保存在浏览器本地存储中）。

## 多人协作

1. 安装依赖：
pm install
2. 启动服务器：双击 start-server.bat 或运行 
ode server.js
3. 浏览器打开 http://localhost:3456/

多人从同一地址打开即可实时同步数据。

## 功能

- 三个课程模块：Inspire / Explorer / Challenge
- 每个模块 48 个课程槽位
- 课程名称、副标题、器材、目标、流程的完整编辑
- 智能粘贴：从表格/文档粘贴自动识别填充字段
- 生成课程文档图片（复制到剪贴板或下载PNG）
- 数据自动保存到 localStorage
- 可选多人协作同步

## 技术栈

纯前端 HTML/CSS/JavaScript，无任何外部依赖。可选 Node.js 服务器用于多人协作。

## 学校知识点（固定知识库）

在课程编辑页的教学流程下方，点击 **提取知识点**。面板默认收起，提取后展开；可随时收起。系统读取当前未保存的课程名称、副标题、器材、教学目标和流程，以固定规则列出公立学校（中国大陆小学、初中）与 IB PYP／MYP 的相关学科主题，无需模型服务或 API 密钥。

- 每项显示课程原文、应用说明、公立学校和 IB 主题参考。只有名称／器材命中时标为“候选关联”；有目标或流程依据时才标为“有教案依据”。没有可靠匹配时提示补充内容，不强行生成。
- 三极管、电容、RC 延时、自激振荡等单独标为进阶拓展，不宣称为小学、初中或 IB 必修内容。
- 提取结果和教师确认状态保存到该课程的 `schoolKnowledge` 字段，通过现有本地／服务器保存流程持久化；不会自动为现有课程批量写入结果。点击“确认并保存”表示教师已核对，不代表官方认证。
- 更改课程内容或知识库版本后，原结果保留并提示重新提取；新结果需要重新确认。文本教案下载会包含知识点及待确认／待更新状态。
- 主题关联是项目维护的教学参考，**不是经过官方指南逐条核验的课程标准对照表**。不承诺固定年级、教材章节或特定 IB 学校的教学顺序。面板提供教育部课程标准公告和 IB 课程框架链接供教师核对；首版实现环境无法访问这些网站，因此没有标注未经核实的官方条目。

知识库和匹配规则位于 `school-knowledge.js`。运行 `npm test` 验证匹配、证据分级、进阶标记、更新提示与现有 46 节课兼容性。仅查看本地 HTML 也能提取和保存到浏览器；服务器模式仍采用现有整份数据保存机制，多人同时写入可能互相覆盖。
