# MakeX Curriculum — Inspire · Explorer · Challenge

MakeX 机器人课程管理系统，支持课程创建、编辑、文档导出和多人协作。

## 直接使用

直接打开 index.html 即可使用（数据保存在浏览器本地存储中）。

## 多人协作

1. 安装依赖：
pm install
2. 启动服务器：双击 start-server.bat 或运行 
ode server.js
3. 浏览器打开 http://localhost:3456/

多人从同一地址打开即可实时同步数据。

## 功能

- 三个课程模块：Inspire / Explorer / Challenge
- 每个模块 48 个课程槽位
- 课程名称、副标题、器材、目标、流程的完整编辑
- 智能粘贴：从表格/文档粘贴自动识别填充字段
- 生成课程文档图片（复制到剪贴板或下载PNG）
- 数据自动保存到 localStorage
- 可选多人协作同步

## 技术栈

纯前端 HTML/CSS/JavaScript，无任何外部依赖。可选 Node.js 服务器用于多人协作。

## 数据保存与同步

运行 `npm start` 启动服务器（默认端口 3456，可用 `PORT` 覆盖）。通过服务器地址打开页面后，编辑会先保存在当前浏览器，再写入服务器；其他页面每 3 秒读取更新。断网时显示“已存本机，待同步”，连接恢复后重试，刷新页面也会保留待同步状态。直接打开 HTML 文件只能使用本地保存。

服务器默认将数据写入 `makex_data.json`；可设置 `MAKEX_DATA_FILE` 指定其他文件。写入成功后才返回保存成功；无效数据或文件写入失败不会替换已保存的数据。启动时若数据损坏会报错退出，避免静默加载空数据。

当前同步采用整份数据保存。多人同时编辑时，最后成功保存的版本会覆盖前一个版本；尚不支持同时合并不同人的修改。建议避免多人同时修改。

## 已恢复的历史数据

原始课程文件存在编码损坏和 JSON 格式错误。现已保留 144 个课程槽位及其字段，恢复可以辨认的中文，并以 `【待核对】` 标记无法准确还原的文字，需人工确认。完整原始文件保存在 `backups/makex_data.original.txt`，请勿将其作为服务器数据文件使用。

## 验证

运行 `npm test` 检查课程读取、保存、重启恢复、无效请求保护和磁盘写入失败保护。测试使用临时数据文件，不会覆盖正式课程数据。
